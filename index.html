4-Bit Binary Adder–Subtractor

Digital Electronics Mini Project

Project Overview

This project implements a 4-bit binary adder and subtractor using Full Adders and XOR gates.

Mode M = 0: Binary Addition

Mode M = 1: Binary Subtraction

Logic Expression: S = A + (B XOR M) + M
